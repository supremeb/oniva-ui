# Loop 5 Motion / Design-Engineering Audit (oniva-ui)

Scope: whole library (`packages/oniva-ui/src`, 76 files touch transition/animation/keyframes), grep-driven + code read. Bars: Emil Kowalski (emil-design-eng, improve/review/find-animation-opportunities, animation-performance), Rauno interfaces, Vercel Web Interface Guidelines, Anthropic frontend-design.
**Method caveat:** docs preview (localhost:4311) was NOT running; this is a static code audit. Live feel (Button press, Select open, Toast stack, Charts draw-in, ComposerLoader) must be verified by the worker with `cd apps/docs && NAPI_RS_FORCE_WASI=1 npx vite preview --port 4330 --strictPort`. Report-only; no library code changed.

## Ground truth from grep
- Tokens (`tokens/motion.stylex.ts`): dur fast 100 / base 150 / slow 250; eases are Material (`0.4,0,0.2,1` standard, `0,0,0.2,1` out, `0.4,0,1,1` in). Reduced motion collapses durations to 0.01ms AND sets `animationName: none` per component (good, consistent).
- `stylex.keyframes` in: charts-styles (grow, growX, fade, draw, pop), overlays-menu (popIn/popOut), Drawer (6 slides + fade), Tooltip, Popover, HoverCard, Dialog, Toast (enter only), Skeleton shimmer, Spinner, Button spinner, ProgressBar stripes, InputOTP caret, TextShimmer, ImageGenerationLoader, ComposerLoader.
- No `:active` press transform anywhere (only color changes in feedback-control.ts, CloseButton). No `will-change`, no `touch-action`, no `overscroll-behavior`. No `transition: all` (good). Focus: `focus.ts` uses `:focus-visible` 2px ring w/ offset (good).

## P0 (feel-breaking / rule-violating, high traffic)

| # | Component | Current | Rule violated | Exact fix |
|---|---|---|---|---|
| 1 | Global easing tokens | `ease-out` = `(0,0,.2,1)`, `ease-in` = `(.4,0,1,1)`, `standard` = Material | emil-design-eng: "built-in curves too weak; use custom strong ease-out" | Replace with `ease-out-quint (0.23,1,0.32,1)`, `ease-in-out (0.77,0,0.175,1)`, `ease-drawer (0.32,0.72,0,1)`; keep old names as aliases so no consumer breaks. |
| 2 | Exits everywhere (Popover, Tooltip, HoverCard, menus, Dialog, Drawer) | Exit uses `ease-in` (`.4,0,1,1`) | "Never use ease-in for UI"; exits should be ease-out and faster than enter | Exit = `ease-out`, 100-120ms (popover/menu/tooltip), 150ms (dialog). Asymmetric: enter 150-200, exit ~60% of enter. |
| 3 | Button (all variants, IconButton, ToggleButton, SegmentedControl item, Tabs tab, Pagination) | No press feedback besides bg color via `:active` | "Buttons must feel responsive": `scale(0.97)` on :active | Add `transform: scale(0.97)` on `:active:not([data-disabled])`, `transition: transform 120ms ease-out-quint` (add `transform` to transitionProperty). Release is the same transition (interruptible). Reduced motion: keep (it's transform feedback, tiny) or drop to 0.99. Icon-only 0.94. |
| 4 | Popover/Tooltip/HoverCard transform-origin | Only `overlays-menu` sets `transformOrigin` (to `--trigger-anchor-point`). Popover, Tooltip, HoverCard, Select/Combobox/DatePicker popovers scale from center | "Popovers scale from trigger, not center; modals stay centered" | `transformOrigin: 'var(--trigger-anchor-point, center)'` on all popover surfaces; fall back to placement-based: `[data-placement=top]` -> `bottom`, `bottom` -> `top`, `left` -> `right`. Verify RAC 1.22 exposes `--trigger-anchor-point` (it does for Popover). Tooltip: also `translate` 2px toward trigger. |
| 5 | Toast | Enter-only keyframe (translateY 12px+scale .98, 250ms); NO exit animation, no stacking, no swipe-dismiss, no pause-on-hover/visibility handling, `maxVisibleToasts: 5` stacks flat | Spatial consistency (enter/exit same direction), interruptibility, find-animation-opportunities "toast stack + swipe" | (a) Exit: slide to enter-side + fade, 180ms ease-out via RAC `isExiting` / `data-exiting`. (b) Stack: front toast full; behind toasts `translateY(-8px*i) scale(1-0.05*i)`, opacity step, collapse on non-hover, expand on region hover (`transition: transform 300ms ease-drawer`). (c) Swipe: pointer-events drag on X (bottom-right) with velocity >0.11 px/ms or >45% width dismiss; follow finger with `transition:none`, `touch-action: pan-y`, release springs back. (d) Pause timer on hover/focus + `visibilitychange`. (e) Layout shift on remove: animate siblings with FLIP/`transition: transform`. |
| 6 | Drawer | Slide uses `dur-base` 150ms + Material out; no drag; no backdrop tied to progress; same curve for all edges | "Drawers 200-500ms, use drawer curve", Vaul-like drag opportunity | Enter 400-450ms `cubic-bezier(0.32,0.72,0,1)` (bottom/side), exit 300ms same curve. Add drag-to-dismiss (pointer events, `touch-action:none` on handle, velocity>0.11 or >50% size, rubber-band 8% resist past open, `transition:none` while dragging, scroll-lock + don't start drag if inner scroller scrolled). Backdrop opacity bound to drag progress. Bottom variant: grab handle 4x36 pill, 44px hit zone. |
| 7 | Command palette | Uses shared `menuStyles.popupEntering` (scale+fade 150ms) | "Never animate keyboard-initiated actions (100+/day); Raycast has none" | Palette: no scale/translate on open; opacity-only 80ms or none. Items: no per-item transitions on arrow nav (`transition: none` on `[data-focused]` background — instant highlight). Keep backdrop fade 100ms. Add `data-opened-by-keyboard` heuristic: skip animation when opened via hotkey. |
| 8 | Switch | Knob moves via `transition: inset-inline-start` (layout property, triggers layout) with Material ease, 150ms | animation-performance: only transform/opacity; Switch is a "squish" opportunity | Position knob once, animate `transform: translateX(var(--travel))` 200ms `ease-out-quint`; on `:active` widen knob (`scaleX`/width via transform 1.15) for pressed feel; track bg transition 150ms. RTL: use `[dir=rtl]` negative travel. |
