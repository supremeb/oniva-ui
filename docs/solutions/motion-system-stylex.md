# Motion system on StyleX (loop 5a)

Tokens in `tokens/motion.stylex.ts`; shared presets in `internal/motion-styles.ts` (`motionStyles`, `enterExit`); primitives in `src/motion/`. No animation dependency. Rules are in AGENTS.md "Motion rules".

## Non-obvious learnings

- **Aliasing a token in a local const breaks `@stylexjs/valid-styles`.** `const ease = motion['--x']; animationTimingFunction: ease` fails lint ("must be one of"), as does `const d = motion`. Always write `motion['--oniva-motion-...']` inline in the style value.
- **Keyframes live in the same file as the `stylex.create` that uses them** (internal/motion-styles.ts). Export the created style objects (`enterExit.scale`), not the keyframes, and compose with `stylex.props(enterExit.scale, xstyle)`.
- **Token vars inside keyframes work** (`transform: \`scale(${motion['--oniva-motion-pop-scale']})\``), so reduced-motion token collapse (pop-scale -> 1, travel -> 0) also flattens keyframes. Still add `media.reducedMotion` branches that swap the keyframe to a plain fade, because a 0.01ms transform animation is invisible but a fade is the intended reduced fallback.
- **RAC state + our state share one selector set.** `enterExit.*` keys on both `[data-entering]`/`[data-exiting]` (RAC Popover/Dialog/Tooltip/Toast) and `[data-state="entering|exiting"]` (our `Presence`). Attribute conditions like `'[data-entering]'` work as StyleX conditions, but descendant forms like `'[data-open] > &'` do NOT. If a child depends on a parent attribute, put the attribute on the child too (AnimatedHeight sets `data-open` on both).
- **Exit must use the exit keyframe for BOTH enter and exit attributes at once.** When RAC flips `data-entering` off and `data-exiting` on mid-enter, the animation-name changes and restarts from the exit keyframe's `from` (full opacity), which pops. Acceptable at 100ms; if it matters use transitions instead of keyframes for that surface.
- **Presence needs three unmount paths:** `animationend` (guard `e.target === e.currentTarget`, children's animations bubble), `getAnimations().length === 0` after a frame (reduced motion / no CSS), and a timeout fallback (500ms). jsdom has none of the first two, so tests fire `animationend` manually.
- **jsdom has no `AnimationEvent`, so React drops `onAnimationEnd`.** `src/test/animation-event.ts` polyfills it and MUST be the first import in `setup.ts` (React caches event-name detection at module load).
- **Animating height:** `display:grid; grid-template-rows: 0fr -> 1fr` + inner `min-height:0; overflow:hidden` is the only interruptible auto-height technique that needs no measuring. Transition `visibility` alongside (it flips discretely at the end, staying visible during close), set `inert` on the inner so closed content can't take focus, and fade opacity faster than the height.
- **Sliding indicator measuring:** refs attach after children's layout effects, so a child hook's first `useLayoutEffect` sees `containerRef.current === null`. Re-measure in a passive effect. Use `offsetLeft/Top/Width/Height` (not `getBoundingClientRect`, which includes ancestor transforms such as a scaling dialog). Position by transform; width/height transition on the out-of-flow absolutely positioned pill (no sibling reflow). Gate transitions on `data-ready` (set one rAF after first measure) so the first placement never animates.
- **WAAPI / inline interop:** dynamic values go through CSS custom properties set via `style` (`--oniva-indicator-x`, `--oniva-digit`, `--oniva-delay`, `--oniva-i`) and are consumed by static StyleX rules (`translate(var(--oniva-indicator-x, 0px))`). This keeps StyleX atomic classes intact; never write `transform` inline over a StyleX transform. For WAAPI, animate with `el.animate(..., { composite: 'add' })` or animate a wrapper, since inline-style/WAAPI transforms override the class transform while running.
- **AnimatedNumber:** columns are keyed by distance from the decimal point (integer digits from the right, fraction by index) so growing 99 -> 100 keeps existing columns rolling and new ones mount at their final digit. Visual layer is `aria-hidden`; a single sr-only span carries the Intl string.
- **TextReveal is append-safe** because words are keyed by token index and the delay is computed relative to the previously rendered word count (a ref updated in an effect). Don't reuse keys across different text, remount with `key`.
- **Press scale is pointer-only:** `:active` on native buttons does scale on Space/Enter keydown in some browsers; for custom elements use `usePressScale` (pointer events only). Add `touch-action: manipulation` to kill the 300ms tap delay.
- `AnimationEvent`-driven exits cause stuck elements when `animation-name` is `none` under reduced motion; the `getAnimations()` check handles that.
