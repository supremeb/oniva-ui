# Loop 5 inspiration: per-site findings

Method note: most pages were read through server text, llms.txt / install.md, shadcn registries and GitHub raw files (richer and more exact than JS-rendered snapshots). One live browser pass on transitions.dev. Per-component live interaction was NOT inspected for affectui, uiarc, evilcharts, cult-ui, motion-primitives, reactbits and kibo beyond index text; motion specs for those are marked [I] (inferred) in the recipes file. Affect UI, Kobra and Arc have paid tiers; only free/index info was used.

## transitions.dev (Jakub Antalik)
43+ transitions, CSS-first, copy-paste snippet with semantic `:root` tokens, `t-*` classes and a reduced-motion guard; CLI `npx transitions-dev add <name>`, agent skill, "Motion Agent" scoring codebase motion 0-100. Library names: Card resize, Number pop-in, Notification badge, Text states swap, Menu dropdown, Modal, Panel reveal, Page side-by-side, Icon swap, Success check, Avatar group hover, Error state shake, Input clear with dissolve, Skeleton loader and reveal, Texts reveal, Tabs sliding, Shimmer text, Organic shimmer (wavy, edge glow), Tooltip, 3D tilt with glare, Drag & drop with physics (zone morphs into image), Image open tilt (iPadOS zoom + bend), Dropdown/plus menu morph, Accordion, Toast, Like button, Learn-more hover, Checkbox check, Spinner-to-check morph, Spinning counter, Toggle, Thinking states, Reasoning stream, Streaming text, Matrix dot loader, Image generation placeholder (dot noise to image), Banner stacking, Text morph, Soft text swap, Donut chart morph, Card stack hover, Confetti burst (Pro), Delete with smoky dissolve (Pro), Pro gradient text, Get Pro rim glow button. All published token values are in `loop5-motion-recipes.md` (house easing `cubic-bezier(0.22,1,0.36,1)`, durations 40/80/150/250/350/400/500ms, blur 2-3px, scale 0.96-0.99).
Standouts: blur is used as a motion smoother on nearly every swap; exits are ~60% of enter; hover tilt tracks pointer on a flat outer wrapper to avoid edge flicker; toggle thumb has a "double bounce" (1px overshoot then 0).
Agent-specific recipes (thinking states, reasoning stream, streaming text, image-gen placeholder, matrix loader) map directly onto our AI folder.

## Affect UI (affectui.com)
157 components plus blocks (Pro tier for some). Homepage live demos: Line chart (scrub to read any day), Morph select (trigger grows into the list), Metrics dashboard block, Donut chart (arcs morph to new period), Number field (push past a limit and it pushes back), Date range picker (numbers follow), Command palette, Voice orb (Pro), Lightbox gallery (Pro), Dock (Pro), Chat thread, Checkout summary (promo code makes total count down), Confirm morph (asks in place with undo), Data grid (Pro: sort, filter, resize, edit), Availability picker, Time dial (Pro), Inbox triage (archive/snooze closes the gap in the list). Title reveals by blur, word, line, or wipe.
Take: strong "interaction-as-demo" philosophy; worth copying Morph select, Confirm morph, Number field rubber-band, Inbox triage list collapse.

## Kobra (kobra.systems)
81 named components on Base UI + shadcn; 10 free. Agents group: reasoning-steps, chat-history (gathers asked questions into one column over blurred transcript), file-diff, image-generation (canvas forming), streaming-text, inline-citations, code-block, task-list, chat-input (Voice Glow, ElevenLabs UI), plan-card, question-card, message, message-scroller (edge controls). Also halftone-dots (image rebuilt as dots morphing between pictures), input-dissolve, magnetic-dropzone, filter-chips (join into one track as neighbours selected, Spotify style), logo-carousel, lightbox (ripple zoom), qr-code (ripples on change), advertisement (rotating line fill), grouped-table (columns glide as row narrows), slider (liquid handle), color-palette (19-swatch wheel), sound (Web Kits Audio cue per press), ai-editor, toast (stacked with progress), direction (RTL provider).
Style rules worth adopting verbatim: 400/700 weights only, 14/13px text, one hairline then shadow, concentric radius (child = parent radius - padding), press scale ~0.99 on surface only, busy button keeps its label (spinner turns in), tabular-nums, designed empty/loading states, entrance `cubic-bezier(0.23,1,0.32,1)` 150-250ms, exit `cubic-bezier(0.4,0,0.6,1)`, RTL logical properties.

## EvilCharts (evilcharts.com)
Recharts and ECharts twins behind one compound API + shared `config` object (labels, colors, icons). Charts: Area, Line, Bar (+Bar Blocks), Composed, Pie (donut, gradient, glow), Radar (filled/lines), Radial (full + semi), Sankey; UI parts: Background (patterns), Brush (zoom), Dots, Legend, Tooltip. Signature: per-series gradients, SVG pattern fills, glow filters, entrance reveal animations, series colours compiled to CSS vars so dark/light swaps with no re-render, Canvas for dense live data vs SVG for design surface. Kobra reuses it as its chart.
