# oniva-ui v0.1 plan

## Outcome

An original, MIT-licensed React design system ("oniva-ui") with the polish and coverage of BoardUI
(dashboards + AI/agent interfaces), styled 100% with **StyleX (Meta)**, accessible via **React Aria**,
shipped as a monorepo on GitHub (`supremeb/oniva-ui`) with a BoardUI-style showcase/docs site,
unit tests, Playwright e2e + axe a11y tests, and CI.

## Non-goals / constraints

- Do NOT copy BoardUI (or any proprietary) source, icons, illustrations or copy. Re-implement from the
  measured design language in `docs/research/design-language.md`. Use lucide-react (ISC) for icons.
- No Tailwind. No runtime CSS-in-JS. All styling = `stylex.create` / `defineVars` / `createTheme`.
- No paid/"Pro" gating. Everything is free.

## Folder conventions (enforced)

```
packages/oniva-ui/src/
  tokens/            colors.stylex.ts, space.stylex.ts, radius.stylex.ts, font.stylex.ts, shadow.stylex.ts, motion.stylex.ts
  themes/            themes.ts (createTheme: dark, accent variants), ThemeProvider.tsx
  components/<Name>/ <Name>.tsx  index.ts  <Name>.test.tsx  <Name>.demo.tsx
  charts/<Name>/     same shape
  ai/<Name>/         same shape (agent / composer widgets)
  widgets/<Name>/    same shape (dashboard widgets: health, finance, profile…)
  internal/          shared helpers (cx utils, useControllableState, formatters) — append-only, coordinate via orchestrator
```

`<Name>.demo.tsx` default-exports `{ meta: { title, slug, category, description }, demos: [{ name, code, Component }] }`.

## Loops (compound engineering: plan → work → review → compound)

- **Loop 1 — Foundation** (1 worker): monorepo, tokens/themes, build, gen-index, docs shell with auto-discovered demos, test infra (vitest + playwright + axe), CI, and 6 exemplar components (Button, Badge, Card, Input, Avatar, Switch) that set the pattern. Review → compound (AGENTS.md + docs/solutions).
- **Loop 2 — Core coverage** (5 parallel workers, disjoint folders): Forms; Overlays; Navigation; Data display + Data table; Feedback + Layout.
- **Loop 3 — Signature** (4 parallel workers): Charts; AI/agent widgets; Dashboard widgets; Landing page + templates.
- **Loop 4 — Hardening**: multi-reviewer code review, a11y/e2e sweep, README/docs polish, compound, publish to GitHub.

Workers do NOT commit; the orchestrator verifies and commits per unit. Workers must run `npm run typecheck`, the unit tests for their folders, and `npm run build` before reporting.
